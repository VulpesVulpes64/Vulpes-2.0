GameX Wire Control Center 1.0.0

Запуск:
1. Установите Python 3.10+.
2. Для работы с реальным USB-геймпадом установите pygame:
   pip install pygame
3. Запустите:
   python gamex_wire_control_center.py

Без pygame программа запускается в режиме симулятора: нажмите кнопку «Симулятор».

Что реализовано:
- мониторинг кнопок, D-pad, стиков и триггеров;
- переназначение цифровых кнопок внутри конфигуратора;
- dead zone, чувствительность, инверсия и кривые стиков;
- настройки LT/RT;
- тест двух каналов вибрации, если поддерживает драйвер;
- RGB-параметры и предпросмотр;
- профили JSON, импорт/экспорт, Default;
- журналирование;
- диагностика RAW-входов;
- состояния INIT/DISCONNECTED/CONNECTED/EDITING/APPLYING/TESTING/ERROR.

Важно:
Физическая запись RGB, переназначений и параметров во внутреннюю память конкретного GameX требует vendor HID-протокола устройства (VID/PID + формат HID report). Для этого в программе предусмотрен класс VendorHardwareAdapter.
